# 🦉 Strix

### Seu novo jeito de compartilhar conhecimento

**Strix** é uma plataforma inspirada em redes sociais, criada com o objetivo de proporcionar um espaço simples para que usuários possam compartilhar conhecimento, ideias e experiências.

O projeto foi construído como uma aplicação full-stack, com este repositório contendo o **backend**.

🌐 **Live Demo:**
https://strix-cyan.vercel.app/

---

## 🇧🇷 Sobre o projeto

O projeto conta com funcionalidades como:

* 👤 Criação e gerenciamento de usuários
* 🔐 Autenticação
* 📝 Criação de posts
* 👥 Sistema de seguidores
* 🔎 Busca por usuários
* 📰 Feed baseado em usuários seguidos
* 🖼️ Perfis com foto e biografia
* ✏️ Gerenciamento de informações do perfil

O objetivo principal do projeto foi colocar em prática conceitos de **desenvolvimento frontend e backend**, integração com APIs, autenticação e gerenciamento de estado.

## 📂 Repositório

Este repositório contém o **backend da aplicação Strix**, desenvolvido com Django e Django REST Framework.

Ele é responsável por fornecer a **API REST**, autenticação, gerenciamento de usuários, posts e sistema de seguidores utilizados pela aplicação frontend.

O frontend está hospedado em um repositório separado e consome esta API.

## 🇺🇸 About the project

**Strix** is a social platform designed to provide a simple space for users to share knowledge, ideas, and experiences.

The project includes features such as:

* 👤 User creation and management
* 🔐 Authentication
* 📝 Post creation
* 👥 Following system
* 🔎 User search
* 📰 Feed based on followed users
* 🖼️ Profile pictures and biographies
* ✏️ Profile management

The main goal of the project was to put into practice concepts involving **frontend and backend development**, API integration, authentication, and state management.
